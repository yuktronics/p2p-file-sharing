Privacy, plainly

Short version: the server helps two browsers find each other, then gets out of the way. It never sees a file.

The one thing that matters

File contents never reach our servers. Your browser sends the bytes directly to the other device over an encrypted WebRTC data channel. The bytes are not proxied, not buffered, not logged, not scanned, and not stored — we could not hand them to anyone if asked, because we never receive them.

That also means we cannot recover a file for you after the fact, and we cannot tell you what a file contained.

What the server does see

  • Room metadata — a random room ID, the number of files, and each file's name and size, so a receiver can show what is on offer before connecting.
  • A 4-digit nearby code, if you use nearby mode, so two devices on the same network can find the same room.
  • Signalling messages — SDP offers/answers and ICE candidates, the connection setup for the peer connection. These are relayed, not stored.

Room state lives in memory only. Close the sender tab (or wait out the grace period) and it is gone. There is no database of your transfers and no history.

What is never collected

  • No crash reporting, no advertising, no tracking SDKs, and no analytics SDK of any kind.
  • No account, no sign-in, no name, no email address.
  • No contacts, photos, location, or device identifiers.
  • No reading of files you did not choose to share.

Relay networks

If a direct connection cannot be made (a strict network or carrier-grade NAT), the app may use a TURN relay to carry the connection. With a relay in the path, the relay operator can observe that an encrypted connection happened and how much data crossed it — but not the contents, which remain end-to-end encrypted between the two devices. When no relay is configured, this never happens at all.

Abuse reports

If you report a transfer, we store the room ID, the reason, and any contact detail you choose to include, so an operator can act on it. Confirmed abuse disables the room immediately. These reports are the only thing kept longer than a session. Ask us to delete one and we will.

Children

The app is not directed at children under 13, and it collects no personal information from anyone, children included. If you believe a child has shared something concerning, report it and we will act.

Your choices

  • Stop sharing at any time: closing the sender tab ends the transfer immediately.
  • Report and request deletion of a report record at any time.
  • Everything else is ephemeral by design — there is nothing to export or delete.

Changes and contact

If this policy changes, the new version will be posted at this address and the change will be described here rather than made silently.

Questions, or a report to escalate: use the report page, or the Report this transfer link on the page where you received the files, which reaches the operator directly.
