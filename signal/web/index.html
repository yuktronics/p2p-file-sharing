Questions, answered

How long are files available?

As long as your tab stays open. Close it and the link dies instantly — nothing was ever uploaded, so there's nothing to delete.

Is there really no size limit?

Correct. The limit is your devices + network, not us. Chrome / Edge / Firefox stream straight to disk; Safari holds files in memory (~4 GB). How sending with no size limit works →

What if we're on a strict corporate network?

Some symmetric NATs block direct P2P. When that happens the app falls back to a TURN relay automatically — the relay only sees encrypted traffic and stores nothing. Direct P2P covers most home / café / campus networks.

Can the receiver get files while I'm offline?

Not in P2P mode — both sides must be online together.
